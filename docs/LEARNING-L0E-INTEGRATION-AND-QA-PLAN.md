# L0.E.0 integration and QA plan

L0.E.0 audits the chain `practice → authorized outcome → immutable evidence → governance eligibility → Mistake Mine → PrepPilot action → bounded study plan → safe dashboard projection`.

The audit uses pure fixtures only. It verifies identity and version lineage, learner ownership, consent, content approval, explanation release, fresh-content availability, target-specific coverage, recommendation traceability and daily-budget bounds. It also verifies that all five preview routes remain server-disabled unless the existing development flag is explicitly enabled.

Active PostgreSQL, Prisma migrations, production APIs and L0.C retrieval scheduling are outside the test boundary.
