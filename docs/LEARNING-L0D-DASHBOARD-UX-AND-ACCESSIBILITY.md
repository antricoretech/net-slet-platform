# L0.D.0 dashboard UX and accessibility

The development-only route is `/dashboard/preview` and is server-gated by the existing preview guard. It provides:

- welcome and preparation status;
- multiple target cards with date provenance;
- daily time-budget control;
- provisional proposed plan;
- target-specific coverage summaries;
- Mistake Mine confidence/error signals;
- explicit disabled persistence and spaced-review states;
- keyboard-operable action selection through native buttons and labelled controls.

The fixture is visibly labelled synthetic and temporary. It contains no answer keys or staff metadata. Existing workspace cards, headings, labels, focusable native controls and responsive grid styles are reused. A future production dashboard requires authenticated server data, consent-aware authorization and accessibility review.
