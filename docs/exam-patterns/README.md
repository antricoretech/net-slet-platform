# Exam-pattern verification ledger

The original master reference is historical/research input, not independently verified production authorization. Treat every national, state and regional exam's currently listed cycle/pattern as `RESEARCH_ONLY` until it is verified for the **exact examination, cycle, subject and language policy** by an authorized reviewer using an organizer bulletin.

For each release-ready pattern create a structured, immutable record with: examination identity; organizer/jurisdiction; cycle; subjects and medium; timer/sections/navigation/attempt caps/scoring; authoritative bulletin URL/file, date and hash; verifier and approval timestamps; test matrix; question bank coverage; publishing status. A new corrigendum creates a new version; historic student attempts retain prior versions. Do not publish `OFFICIAL_PATTERN` via an unsupported import.

The `packages/exam-rules` package currently contains **validation scaffolding only**—not a complete verified scoring engine.
