# L0.D.0 PrepPilot design

PrepPilot is a provisional study-task planner built on L0.A practice configuration, L0.B mistake evidence and L0.B.1 governance. It is not a spaced-retrieval scheduler and does not persist learner plans.

The profile separates learner-entered data (targets, language, time, priorities and familiarity) from system-qualified data (verified examination dates, approved syllabus versions and authorized evidence). Multiple targets remain separate by target ID, examination, cycle and subject.

Next-best actions require learner ownership, active optional-personalization consent, approved syllabus mapping and content availability. Mistake remediation is ranked ahead of coverage when authorized repeated-error evidence exists. Fresh practice requires an explicit fresh approved-content flag. Unavailable actions are not returned as executable recommendations.

No exam date is invented. Learner-supplied dates are displayed as provenance-labelled dates without a verified countdown. No cross-exam equivalence is inferred from topic names; cross-exam reuse requires an approved mapping.
