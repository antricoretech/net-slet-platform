# L0.B.1 content-readiness assessment

The repository contains QBMS lifecycle and projection contracts, but the active database was not queried for this increment. Therefore no approved-content, translation, licensing, explanation or fresh-inventory counts are asserted.

The pure validator requires each candidate to have:

- published question-version status;
- approved answer-key version;
- reviewed explanation;
- approved translation for the requested language;
- licensed or permitted source material;
- syllabus/topic linkage and reviewed concept mapping;
- fresh status and an approved parallel-question relationship for follow-up practice.

Missing any required field produces an explicit insufficient-content state. Previously exposed question versions are excluded from fresh inventory. The synthetic fixtures in unit tests are labeled data and do not represent approved production content.
