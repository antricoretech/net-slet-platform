# Content Track C0.B — Translation and Explanation QA

Translation eligibility requires an approved human review, equal option cardinality, answer-key consistency, preserved mathematical tokens, terminology review and reviewer/timestamp metadata. Missing or outdated translations are blocked.

Answer-trust requires a reviewed explanation version tied to the current answer-key version, reviewed correct and distractor rationales, concept references, SME metadata and source attribution or an explicit unavailable citation state. AI-generated evidence cannot satisfy this gate.

Mathematical content must carry a non-empty LaTeX representation with balanced delimiter markers and must pass rendering QA before publication.
